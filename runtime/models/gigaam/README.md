# Локальные модели GigaAM

При первом запуске speech worker автоматически скачивает выбранную модель
GigaAM в эту папку. По умолчанию используется `v3_rnnt`.

Файлы весов `*.ckpt` и токенизаторов `*.model` не добавляются в Git. Для
офлайн-установки их можно перенести в эту папку вручную до запуска проекта.
