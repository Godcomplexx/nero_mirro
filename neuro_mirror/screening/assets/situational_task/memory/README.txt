Пилотные материалы группы «Память» из приложения Б, редакция 3 от 30.10.2026.

СБС-ПАМ-01 — входная форма, подключена к тестовому экрану.
СБС-ПАМ-02 — выходная форма, зарезервирована для выходного скрининга.
СБС-ПАМ-03 — запасная форма после прерывания уже предъявленного входного нарратива.

Материалы остаются demo_only=true и enabled_in_screening=false, пока не реализованы
выбор специалистом, предзаписанное аудио, правила прерывания и полный экран проверки.
